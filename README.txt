TIMBUNG POKHARI TREK CHECKLIST — INSTALLABLE WEB APP

This package must be hosted on an HTTPS website before Android/iPhone browsers can install it to the home screen. Opening index.html directly from a downloaded file does not enable installation.

Files:
- index.html: checklist app
- manifest.webmanifest: app name and home-screen settings
- sw.js: offline caching
- icon-192.png and icon-512.png: app icons

To install:
1. Upload all files to an HTTPS static host such as GitHub Pages or Netlify.
2. Open the published HTTPS address in Chrome on Android.
3. Tap ⋮ > Add to home screen or Install app.
4. On iPhone, open the HTTPS address in Safari > Share > Add to Home Screen.

Important: progress currently saves separately on each device. This app package does not sync marks between members; live shared progress needs a shared database.
